# AMAC 基金业协会公示数据爬虫

这是一个用于抓取中国证券投资基金业协会（AMAC）公开信息的 Python 爬虫，面向 CVC 研究里的基金识别与交叉验证场景。

当前脚本支持抓取 5 张公开表，默认按数据量由小到大执行：

- 基金公司私募投资基金
- 证券公司直投基金
- 证券公司私募投资基金
- 私募基金管理人
- 私募基金产品（最大表，最后执行）

## 数据来源

- 网站：<https://gs.amac.org.cn>
- 类型：AMAC 信息公示系统公开数据
- 方式：按页读取公开列表接口，并在同一轮中进入每条记录的公开详情页
- 完整性：列表字段与详情页全部结构化字段合并成功后，记录才会落库

## 环境要求

- Python 3.10+
- Windows / macOS / Linux 均可

安装依赖：

```bash
pip install -r requirements.txt
```

## 快速开始

1. 列出支持的表名：

```bash
python amac_crawler.py --list-tables
```

2. 先做列表接口联通性测试（只请求第一页，不落盘）：

```bash
python amac_crawler.py --smoke-test "私募基金管理人"
```

3. 抓取全部 5 张表：

```bash
python amac_crawler.py
```

4. 指定输出目录：

```bash
python amac_crawler.py --output-dir ./output
```

## 常用命令

断点续爬：

```bash
python amac_crawler.py --resume "私募基金产品" 8750
```

从数据库自动跳过已完整入库的页：

```bash
python amac_crawler.py --repair "私募基金产品"
```

补漏全部表：

```bash
python amac_crawler.py --repair-all
```

`--repair` 和 `--repair-all` 仍保留原命令名，但会执行完整字段抓取；不会先写入列表版记录再二次补详情。

## 完整字段与断点机制

- 每条记录先获取列表 API 的全部原始字段，再读取对应详情页。
- 详情页的键值字段会动态解析，不写死为少数固定列；例如私募基金产品会包含“基金类型”“基金备案阶段”“注册地”“币种”等。
- 详情页中的多行表格会以 JSON 形式保存在 `详情表_N` 字段中，避免一对多数据被压扁或丢行。
- API 与详情页出现同名字段时，两者都会保留；详情页的重名字段使用 `详情_` 前缀。
- 同一页的全部详情都成功后，才通过一个 SQLite 事务提交。任意一条详情失败，该页不会留下半完整记录，下次运行会重新抓取整页。
- 已完整提交的页会自动跳过，因此进程中断后可直接重新运行同一命令。

## 输出说明

- 默认输出目录为脚本同级的 `output/`
- CSV 编码为 `utf-8-sig`
- 列表 API 表头会转换为中文；详情页沿用官网字段名
- `amac_full_fields.sqlite3` 是完整性与断点状态的主数据库
- CSV 从数据库中的完整记录流式导出，不包含详情抓取失败的半成品

典型输出文件：

- `amac_私募基金产品.csv`
- `amac_私募基金管理人.csv`
- `amac_证券公司私募投资基金.csv`
- `amac_证券公司直投基金.csv`
- `amac_基金公司私募投资基金.csv`

## 注意事项

- AMAC 接口存在风控和偶发失败，脚本内已加入随机延时、预热请求和自动重试。
- 若接口或详情页出现新字段，脚本会把字段并集动态加入数据库记录和 CSV 表头。
- 全字段模式会对每条记录多访问一次公开详情页，运行时间明显长于只抓列表；请保持单进程和温和限速。
- 建议不要把请求频率调得过高，避免触发访问限制。
